# 🧊 Vaccine Cold Chain Monitoring Dashboard

A web-based dashboard for monitoring vaccine storage temperatures and identifying cold chain breaches.

## Features

- View vaccine temperature records
- Search by Reading ID or Box ID
- Filter records by Safe or Breach status
- Display temperature and location details
- View detailed information for each reading

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
